# SmartTaskbar

SmartTaskbar is a heavily modified version of the original SmartTaskbar for Windows 11, with a Rust controller and settings app. It keeps the Windows taskbar and its controls, with an optional floating layout.

[Download the Windows installer](https://github.com/PlasticBuild/SmartTaskbar/releases/latest)

Windows 11 on a 64-bit Intel or AMD PC. Open the release's **Assets** section and run **SmartTaskbar-Setup.exe**.

- Intelligent auto-hide keeps the taskbar visible until a window covers it and lets you reveal it from the edge.
- Set the activation zone and reveal delay separately for each display, including stacked monitors.
- Choose a floating or full-width taskbar and adjust transparency, icon size, and animations.
- Pause SmartTaskbar from Settings or turn on optional inline media controls.
