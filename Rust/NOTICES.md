The Rust executable embeds taskbar appearance profiles from this SmartTaskbar project. The accompanying SmartTaskbar MIT license identifies ChanpleCai, copyright 2018–2021. Retain the notice with distributed copies and substantial portions of the licensed work. [Upstream license](https://github.com/Oliviaophia/SmartTaskbar/blob/main/LICENSE)

The stage script copies the Rust standard library and dependency notices into the release folder. The package includes each crate’s license text and a list of versions. [Rust licenses](https://www.rust-lang.org/policies/licenses)

The appearance integration calls a separately installed portable Windhawk host and its taskbar, Start menu, notification center and flyout positioning mods. Their individual notices apply to their respective distributions. [Windhawk](https://github.com/ramensoftware/windhawk) and [Windhawk mods](https://github.com/ramensoftware/windhawk-mods)

Setup offers MSEdgeRedirect as a separate optional executable alongside its license and corresponding source archive. [MSEdgeRedirect release](https://github.com/rcmaehl/MSEdgeRedirect/releases/tag/0.8.0.0)
